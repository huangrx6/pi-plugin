# 终端使用体验调整

各扩展独立安装、独立提供入口；交互遵循 [终端交互约定](terminal-ui.md)。记录以下已落地行为与验证边界。

## 当前实现

| 领域 | 调整后的行为 |
| --- | --- |
| 自动压缩 | 按总窗口阈值调用原生压缩，成功后请求继续未完成的任务；移除独立归档、正文副本和召回工具。 |
| 策略说明 | 记录触发原因与实际注入要求，详情按需展开，变化时才提示。 |
| 任务操作 | 使用有高度边界的单列窗口浏览、搜索和操作任务；当前、已完成、已归档与全部任务在同一窗口切换。 |
| 额度查询 | 区分订阅窗口、账户余额和密钥限额，标记旧数据与查询错误。 |
| 终端通知 | 按运行结果、终端协议和复用器转发处理，提供独立检测与测试。 |
| 显示层级 | 日常操作通过各自入口完成；状态条和自定义 Footer 仅承载摘要。 |
| 文件布局 | 配置与跨会话状态分层；无持久化需求的扩展不创建目录，旧归档只保留为备份。 |

自动压缩只保留占用、暂停/恢复和阈值三个操作层级。阈值使用模型总窗口作为分母；旧配置迁移保留原来的实际触发比例，详见 [配置迁移](data-migration.md)。

## 验证范围

各包独立执行 `npm run check` 和 `npm test`，文档执行 Markdown lint；安装和迁移脚本另做语法与临时目录验证。

- 自动压缩使用真实 Pi SDK 与离线模型流验证续跑生命周期，另覆盖用量未知、阈值、取消和会话变化。
- 策略记录验证注入与流程决策，不宣称模型已遵守要求或工作已完成。
- 任务测试覆盖工作区持久化、并发冲突、窗口内状态操作、百项列表滚动与终端显示。
- 额度使用固定响应验证适配契约；不把固定响应测试等同于真实账户对账。
- 通知通过字节级和终端环境组合测试；实际系统通知送达仍需在目标终端验收。
- 迁移在临时目录验证冲突、重复执行、数据库占用和失败回滚，不覆盖现有用户状态。

命令行验证不等同于所有终端的视觉验收或真实模型服务端到端测试。
