# 终端使用体验调整

先按依赖顺序推进；用户确认并行后，互不依赖的包并行实施，每项独立通过相关检查。各扩展独立安装、独立提供入口，不增加扩展之间的依赖。

- [x] 1. 上下文整理：成功后恢复被中断的工作；取消、新输入、会话变化不误恢复；显示预算口径和整理结果。
- [x] 2. 策略说明：记录本次触发原因、实际注入的要求和下一步；详情可查看，变化才提示。
- [x] 3. 任务操作：默认直接进入任务列表，选择任务后按状态操作；保留旧命令兼容。
- [x] 4. 独立 UI：主要操作和解释不依赖自定义 Footer；使用紧凑、可换行的本地视图。
- [x] 5. 额度适配：补充有官方接口的余额来源，区分套餐、余额、用量，处理未知值和过期请求，提供独立查询入口。
- [x] 6. 通知适配：区分终端协议和复用器转发，提供检测/测试入口，限制在终端模式输出控制序列。
- [x] 7. 收尾：更新各包文档、版本与变更记录，运行相关检查及回归测试，记录实际验证边界。

## 验收边界

- 自动续跑验证成功、失败、取消、新输入、会话切换和重复触发路径。
- 策略记录描述实际发生的注入与流程决策，不宣称模型已遵守或测试已通过。
- 日常任务操作无需了解内部命令分类；旧调用方式继续有效。
- 额度适配使用官方公开响应契约和固定响应测试；真实账号对账未执行时明确注明。
- 终端协议通过字节级与环境组合测试；实际桌面通知送达需要在对应终端和操作系统验证。
- 不发布、不自动提交，不覆盖调整前已存在的未提交修改。

## 已验证进展

- 八个扩展共 1253 项测试通过；全部包通过各自的语法或类型检查与发布包预检。
- 任务、上下文、策略、额度和通知都提供 Pi 原生独立入口；任务状态条默认最多两行，Footer 只承担摘要展示。
- 策略说明通过 213 项测试；Todo 核心回归与新增交互共 890 项测试通过，并覆盖窄窗口、中文换行、emoji 和控制字符处理。
- 上下文整理通过 28 项测试，包含真实 Pi SDK 的成功续跑、取消、新输入抢占和临时执行约束保留路径。
- 额度状态通过 39 项固定响应、生命周期和主次视图测试；通知通过 54 项协议、复用器、运行结果和非交互输出测试。
- Footer、权限与技能入口共通过 29 项 UI 测试；支持紧凑/完整/原生 Footer、静默取消和可展开的技能活动记录。
- CI 统一调用包内检查与测试：修复不存在的旧策略测试入口，并为任务与通知补齐测试 gate。
