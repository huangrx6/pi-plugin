# 设计说明

常驻摘要控制信息密度，按项浮层提供细节。会话、Token、上下文是固定的三个核心入口，通用外部状态集中在更多入口。只有一个浮层控制器，不再维护表格和信息带两套布局。

## 数据与生命周期

`index.ts` 负责宿主事件与配置装配，`metrics.ts` 提供可注入单调时钟的计时器，`data.ts` 聚合结构化快照。`render.ts` 纯函数生成摘要、点击区域和带标签/数值/注释角色的卡片行，`component.ts` 管理锚定位置、输入监听和释放，`input.ts` 识别键盘关闭动作并被动观察终端鼠标与焦点报告。配置、文本清理与字符宽度各自独立。

会话启动、切树、压缩和运行结束从 `getBranch()` 重建累计值；消息结束增量更新，轮次结束刷新上下文投影，运行结束与持久化消息校准。渲染和等待首 Token 的 ticker 不扫描历史，也不重新构建上下文投影。渲染时只读取较小的公开状态集合，保证外部状态及时刷新。

每次请求至 assistant 结算只生成一个自有计时记录；重试钩子不重置已开始的窗口。非空内容增量结算 TTFT，首增量之后停止等待 ticker。工具按 ID 记录派发至结束，缺少起点时采用宿主上报时长。记录仅含版本、类型、耗时、输出量和失败标记，不保存提示词。

计时记录使用本扩展自有的 `pi-footer-composer-metric` custom entry，不进入模型上下文。恢复时校验版本、有限非负数和 TTFT 窗口。持久化失败的记录暂存在内存中，当前运行仍能显示；切换会话分支时清除。

## 统计口径

Token 总数 = 未缓存输入 + 缓存读取 + 缓存写入 + 输出。缓存命中率 = 累计缓存读取 / 累计全部输入，避免用最后一步的缓存比例描述整个会话。包括 assistant、带用量的工具结果、压缩、分支摘要和宿主额外用量；不读取其他分支。

TPS 使用同一批成功且上报输出数、具有首内容计时的记录做 `Σ输出 / Σ(总耗时 − TTFT)`。仅纳入输出不少于 100 Token、首内容到结束的窗口不少于 100 毫秒的调用，避免短回复与缓冲突发抬高速率；缺少首内容计时不回退端到端速度。公式与门槛参考 [CC Switch 的速度计算](https://github.com/farion1231/cc-switch/blob/main/src/components/usage/format.ts#L181-L299)。首内容包括非空文本、思考或工具参数；隐藏推理缺少增量时只能近似衡量生成速度。

速度筛选不影响 Token 用量、模型用时与 TTFT 累计。失败与取消仍计为步骤，但从 TPS、TTFT 和模型用时中排除。保存的计时记录格式保持不变，恢复时按新公式重新汇总；没有计时记录的历史步骤保留用量，详情显示计时覆盖。

上下文已知 Token 与容量时从同一分母重算百分比；未知值不转成零。只展示宿主总量、容量、剩余与进度，不使用会话累计输入估算上下文组成。

## 交互与宿主边界

颜色使用四个层级：中性面板底色、低对比边框、次要标签和主要数值。通过宿主公开的 `Theme.style` 编码 RGB 并适配终端色彩能力；依据 `appearance` 选择深浅底色，旧 API 回退终端背景。整条边框行与内容行都铺满背景，避免角字符的底色断层。不复用消息或选择控件的强调底色。标题栏承载标题、可选总量和关闭按钮；卡片正文只留指标及必要的缺失计时提示。

按摘要段的显示列生成点击范围，普通左键按下只认领目标，click 再切换卡片。双击、拖动、修饰键点击不切换。卡片打开时临时捕获键盘焦点，通过自身 `handleInput` 处理 Esc，兼容普通转义码、Kitty CSI-u 与 xterm 增强编码，忽略按键释放。编辑输入监听先关闭卡片、恢复宿主原有焦点，再让同一次输入继续分发到编辑器。Esc 不再依赖全局旁观监听关闭，避免进入编辑器的中断动作；面板关闭后的正常中断行为不变。关闭、重载或释放时移除所有监听。卡片内普通文本保留宿主选择行为，滚轮只滚动卡片。

浮层位于入口上方，超出右边界时向左移动；缩放后重新计算宽度、位置与可见行。布局测量包含行间空白、面板上下留白及单行底栏；点击按摘要实际所在行定位，关闭按钮使用同一份标题行坐标。标题与关闭符号使用相同字重；较小的全角 `ｘ` 占两列，右边缘与正文数值列对齐，ASCII 模式回退单列 `x`。渲染与命中共用符号宽度和坐标，点击范围向四周各扩一字符，字号由终端字体统一决定。浮层的显示、切换和隐藏只请求差量重绘，不调用 `requestRender(true)`：隐藏区域由宿主恢复，避免无关图片被整屏清理。尚未打开时调用关闭不会触发重绘。浮层与终端侧边、顶部保持间隔，下沿紧邻底栏；摘要从首列开始，不增加上下空行。终端过小时使用宿主详情对话框；缺少浮层或输入监听 API 时也回退。

全屏宿主在扩展输入监听之前消费鼠标与焦点报告，因此仅在卡片打开时通过公开的 `process.stdin` 数据事件旁观 TTY 输入。普通左键在卡片边界外按下，或终端上报失焦时，收起卡片；卡片内点击与底栏入口交给宿主继续处理。边界优先采用浮层公开的 `getBounds()`，旧 API 回退已计算的布局。观察器处理分包、连续报告与粘贴边界，不把粘贴内容识别为点击；不消费输入、不修改终端模式、不替换或重排宿主监听。切换卡片后旧回调通过代次检查失效，避免同一次输入把新卡片关掉。

内容按字段分组后排版，字段之间插入一行空白，自动换行保持连续。短记录沿右边界对齐；长段落固定在右侧内容区，续行共享左边界，避免短尾行逐行右对齐造成阶梯形布局。通用换行器优先沿空白、逗号、顿号和分号换行，单个超长条目仍按完整字素拆分。只识别文本分隔，不识别服务名称或诊断协议。面板宽高继续受终端与页边距限制，标题和关闭按钮固定，正文超高时滚动；状态变短后钳制滚动位置，保证内容重新可见。

外部状态只依赖公开的 key/value 集合，由用户精确选择。不导入发布者代码，不监听发布者私有事件，不约定 key 前缀，不从文本推导严重度或数值。隐藏 key 同时从未映射项中保留，避免重新泄漏到界面。

## 配置升级

v5 采用小配置模型。旧布局先完整校验并备份原始字节，再抽取当前视图的精确状态选择器；不自动启用旧 remaining 兜底，无效配置不覆写。原子保存完成后才应用新模式。备份位于扩展数据根的 `.backups/`，运行时不读取。
