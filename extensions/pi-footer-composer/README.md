把工作目录、模型、上下文占用和已发布状态放进带标签的行。默认紧凑显示，诊断时展开；配色沿用当前 Pi 主题，中文与组合字符按显示宽度布局。

## 快速开始

在本扩展包目录中执行，单独安装此扩展：

```bash
pi install "$PWD"
```

重启 Pi 或执行 `/reload`，默认启用紧凑视图。输入 `/footer` 选择显示方式。

## 三种视图

| 命令 | 显示内容 |
| --- | --- |
| `/footer compact` | 环境、模型、状态三个信息组；默认模式 |
| `/footer full` | 展开为环境、模型、资源、集成、配置五个信息组 |
| `/footer native` | 停用本渲染器，恢复 Pi 原生底栏 |
| `/footer` | 打开原生选择器；取消不改变当前模式 |

**紧凑视图**保留工作目录、Git 分支、会话名、模型与思考等级、套餐状态、上下文占用和配置状态。它隐藏累计 Token、缓存、费用和集成状态。

**完整视图**额外展示会话用量与集成状态。`↑` / `↓` 表示输入与输出 Token，`R` / `W` 表示缓存读取与写入，`CH` 表示最近一条助手消息的缓存命中率，`$` 表示已记录的费用。

这里的“三行 / 五行”是信息分组：空组不占行，窄终端会折行，超宽单元格会裁切。上下文占用未知时显示 `?`，而不是零。

## 状态如何归类

从 Pi 的公开状态集合读取文本，按状态 key 归类。同组按 key 排序；未知 key 进入配置组。

| Key 前缀 | 紧凑视图 | 完整视图 |
| --- | --- | --- |
| `quota:` | 模型组 | 模型组 |
| `context:` | 状态组 | 资源组 |
| `config:` | 状态组 | 配置组 |
| `integration:` | 隐藏 | 集成组 |
| `usage:` | 暂未显示 | 暂未显示 |
| 其他 | 状态组 | 配置组 |

无上述前缀时使用兼容规则：精确 key `quota` 归模型，精确 `mcp` 或包含 `lsp` 归集成，精确 `mode` 或包含 `policy` 归配置，包含 `context` / `qos` 归上下文。其余进入配置。

完整视图的用量来自会话记录；当前不会展示自定义 `usage:` 状态。

## 显示与边界

- 先清理上游文本的终端控制序列，再统一使用 Pi 主题着色；有意保留的换行按多行单元格显示。
- 布局以字素为单位测量与裁切，兼顾中文、组合字符和 emoji；实际字宽仍取决于终端与字体。
- 用量从会话记录汇总，在轮次结束后刷新；Git 分支变化触发重绘。
- 视图选择保存在当前扩展进程中，不写配置文件；重新加载后回到紧凑模式。
- Pi 的自定义底栏采用替换语义，同时启用多个渲染器时可能互相覆盖。
- 原生底栏的部分内部标记无法通过公开接口读取；需要完整原生信息时执行 `/footer native`。

## 开发

在本包目录运行：

```bash
npm ci
npm run check
npm test
```

`index.ts` 负责状态收集、视图切换与事件接线；`layout.ts` 负责文本净化、显示宽度、折行和裁切。测试覆盖布局宽度及三种视图的交互。
