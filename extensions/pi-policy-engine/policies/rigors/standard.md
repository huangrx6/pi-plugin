# Standard Workflow

Before starting, form a compact Task Contract containing:

- Goal
- Confirmed facts
- MUST constraints
- MUST NOT constraints
- Verification criteria

Then work to the execution intent:

- If mutation is requested: inspect the relevant implementation, create a minimal implementation plan, execute it without unnecessary ceremony, and verify against the Task Contract.
- If the task is read-only: do not perform the mutation phase — inspect, analyze or review, and report findings validated against the Task Contract.

Do not expand into unrelated architecture work unless required by evidence.
