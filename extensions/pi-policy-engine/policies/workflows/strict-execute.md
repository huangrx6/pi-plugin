# Strict Workflow — Execution Phase

The plan has been approved. Execute the approved scope in bounded waves.

For each wave:
1. Make only the coherent changes required by the approved plan.
2. Verify the wave.
3. Re-check the active Constraint Ledger.
4. Stop and re-plan if a core assumption becomes false or scope must materially expand.

At completion, report verification against the original constraints and explicitly identify anything not verified.
