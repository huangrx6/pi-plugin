# Strict Workflow — Planning Phase

This turn is PLAN-ONLY. Do not mutate files, configuration, infrastructure, or external state.

Produce a concise but explicit Task Contract and Constraint Ledger:
- F# = confirmed facts
- C# = MUST / MUST NOT constraints
- A# = assumptions that still need evidence
- V# = verification conditions

Perform the inspection/research needed to remove material uncertainty. Then provide a bounded implementation plan. Each plan step should identify which constraints it satisfies and how it will be verified.

Stop after the plan and ask for approval. Do not start implementation in the same turn.
